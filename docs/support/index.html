そっと サポート

iOSアプリ「そっと」の使い方や不具合に関するお問い合わせ窓口です。

お問い合わせ

sotto.support@gmail.com

端末の種類、iOSのバージョン、問題が起きるまでの操作手順を添えていただくと確認しやすくなります。

個人情報を送らないでください

記録内容、添付写真、電話番号、住所、現在地、相談内容などはメールに添付しないでください。

緊急時・相談が必要な場合

このメール窓口では緊急対応や個別相談を行っていません。今まさに危険がある場合は110番へ連絡してください。相談先はアプリ内の「相談窓口」から確認できます。

見守り機能について

時間になると端末へ通知し、通知からSMS作成画面を開きます。iOSの仕様によりSMSは自動送信されません。宛先と本文を確認し、送信を押してください。
