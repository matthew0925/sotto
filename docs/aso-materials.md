## 説明文（本文）

```
ひとりで抱え込まなくていい。「そっと」は、あなたの日常にそっと寄り添う、
パーソナルセーフティアプリです。

■ 長押しでSOS
ホーム画面を開けば、いつでもすぐに押せる場所に。1.5秒の長押しで、
110番（警察）へ発信の準備が整います。押している間だけ進み、離せば止まります。
誤って押してしまう心配はありません。相談窓口として使いたい方のために、
性犯罪・性暴力被害者のためのワンストップ支援センター（#8891）へは
ホーム画面から別途1タップで発信できます。

■ 帰宅チェックイン（見守り）
出かける前にセットしておくと、時間になっても「無事です」を押さなければ、
あなたが選んだ人にそっと知らせが届きます。知らせには現在地も添えられるので、
何かあったときも助けを呼びやすくなります。

■ 記録（あなたの端末だけに）
気になったこと、違和感、出来事の日時や状況を、思い出せる範囲で少しずつ
残せます。記録は暗号化してこの端末にだけ保存され、クラウドには一切送りません。
Face ID・パスコードで守られているので、誰にも見せなくて大丈夫です。

■ 相談窓口
性犯罪・性暴力のワンストップ支援センター（#8891）、DV相談ナビ（#8008）、
警察（110番）など、一人で抱え込まなくていい相談先をまとめています。
年齢・性別を問わず相談できます。あなたは悪くありません。

■ プライバシーについて
・アカウント登録は不要です（氏名・メール・電話番号の入力なし）
・位置情報は見守り中のみ取得し、指定した連絡先への通知にのみ使われます
・記録やあなたの情報がサーバーに送信されることはありません
・設定からいつでも、この端末のすべてのデータを削除できます

「そっと」は、緊急通報（110番）の代わりになるものではありません。
今まさに危険な状況にあるときは、迷わず110番へ連絡してください。
```

## 審査ノート（App Review情報 / 補足情報欄に貼り付け）

```
■ このアプリについて
「そっと」は、性犯罪・DV・ストーカー被害等、個人の安全確保を目的とした
パーソナルセーフティアプリです。緊急通報番号（110番）の代替ではなく、
アプリ内でもその旨を明記しています。

■ ログインについて
本アプリはアカウント登録機能を持たないため、テスト用のログイン情報は
ありません。起動後すぐにすべての機能をご確認いただけます。

■ 位置情報の利用について
・位置情報は「使用中のみ」の権限のみ要求します（常時位置情報は要求しません）
・「見守りチェックイン」機能が有効な間のみ取得し、タイムアウト時またはユーザー
  が明示的に送信操作を行った際に、ユーザー自身が選んだ連絡先へのSMS作成画面に
  地図リンクとして挿入するためだけに使用します
・位置情報が弊社または第三者のサーバーに送信されることはありません

■ 通知について
チェックインのタイムアウトを知らせるローカル通知のみを使用します。
プッシュ通知サーバーは使用していません。

■ SMS・電話機能について
iOS標準のMFMessageComposeViewController（メッセージ作成画面）とtel:リンクを
使用しています。ユーザーの確認・送信操作なしに、アプリが自動でSMSを送信したり
発信したりすることはありません。

■ データの取り扱いについて
氏名・メールアドレス等の個人情報は一切収集しません。記録機能のデータは
端末内でAES-GCM暗号化され、Face ID/パスコードでロックされます。設定画面から
いつでも全データを削除できます。詳細はプライバシーポリシーをご参照ください。
```
